# Turf features: value, cost and plans

One file per feature, agreed one at a time. Each file says what the feature does, where its data lives, what it costs Turf to run, and how it compares with competitors. It ends with **the amount of the feature in each tier, what that costs Turf, and the price the feature sells for**.

Features are priced on their own. Plan prices are not fixed yet: they come later from adding up the features in each tier, in [the plans doc](../plans/README.md).

Every feature file uses the same five tiers:

| Tier | Who |
| --- | --- |
| **Free trial** | Anyone, for 7 days |
| **Solo** | 1 person who does everything |
| **Duo** | Exactly 2 people (partners, or a caller and a closer), both seeing everything, no roles to set up |
| **Team** | 3 or more people with roles (owner, team lead, callers, closers, researchers, administrators), priced per seat |
| **Pro** | A Team with power features, priced per seat |

**Clients and partners are free seats** in every tier: they only see what is shared with them and never call anyone. Only people who work leads count as seats.
