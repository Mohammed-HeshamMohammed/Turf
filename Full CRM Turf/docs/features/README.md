# Turf features: value, cost and plans

One file per feature, agreed one at a time. Each file says what the feature does, where its data lives, what it costs Turf to run, how it compares with competitors, and, at the end, **how much of it each plan gets and at what price**.

Plans referred to in every file (prices in [the SaaS plan](../saas/README.md); Pro is not final yet):

| Plan | Price |
| --- | --- |
| Free trial | Free, 7 days |
| Solo | $150 / month |
| Team | $129 per seat / month (2+ seats) |
| Pro | ~$229–249 per seat / month (to be decided) |
