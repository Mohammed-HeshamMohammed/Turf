# Caller Whale docs

Everything written about Caller Whale that is not code. Each folder has one job:

- [Legal](legal/README.md): Terms, privacy, consent and calling rules (TCPA, 10DLC, state rules), and what the lawyer has decided.
- [Plans](plans/README.md): Plans for work that is being built or about to be: what, why, the steps and what is left.
- [Research](research/README.md): Notes and sources behind a decision (legal, market, carriers, tools), before it is settled.
- [Tasks](tasks/README.md): One file per area (calls and texts, security, testing and so on) with its open tasks and who has them.
- [Team](team/README.md): Who is on the team, what each person owns and decides, and how work moves between people.
- [Flow charts](flow-charts/README.md): Diagrams of how things work: sign-in, a call, an import, a payment, how work flows through the team.
- [Ideas](ideas/README.md): Ideas that are not plans yet. When one is picked, it moves to plans/.
- [Reviews](reviews/README.md): Reviews and revisions: UI, security and code reviews, what was found and what was changed.
- [Operations](operations/README.md): Running the live system: servers, deploys, backups, monitoring, secrets and what to do when something breaks.
- [Design](design/README.md): How the apps look and feel: references, screens and design decisions.
- [Pricing and market](pricing-and-market/README.md): What each feature costs Caller Whale, its sell price, and the market and competitors.
- [Product](product/README.md): What Caller Whale is and who it is for: the product as a whole.
- [History](history/README.md): Finished plans and old decisions, kept so the reasons are not lost. The old docs folder, as it was when it left the repository, is in [history/old-docs](history/old-docs/README.md).
