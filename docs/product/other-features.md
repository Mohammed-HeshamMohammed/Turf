# Everything else

The rest of Caller Whale. Each part feeds the calling: better lists, better follow-ups, a team that works together.

| Part | What it does | How it helps the calling |
| --- | --- | --- |
| **Importing lists** | Bring in any list (county exports, PropStream, any CSV), map the columns, merge repeats. The original is never changed. | Callers start from clean lists. |
| **Skip tracing** | Checks and ranks the phone numbers a list already has, puts the best number first, and blocks do-not-call numbers. | Fewer wasted calls on bad numbers. |
| **CRM** | Leads, stages, tasks, notes, deals and handoffs between people. "Needs you today" shows what is due. | Every lead has an owner and a next step. |
| **Team chat and inbox** | Chats and groups for the team, and email, beside the leads. | The team talks where the work is. |
| **Leads map** | The leads on a map, by area, with a card for each property. | Plan calls and visits by area. |
| **AI campaigns** | AI writes an email or message for each lead, sends it in steps and reads the replies. | Warms up leads before and after calls. |
| **Exports** | Call lists, mail lists and reports, as CSV or PDF. | Use the data in other tools. |
| **Backup and restore** | Deleted lists can come back for 30 days; whole projects can be backed up. | Nothing is lost by mistake. |
| **Accounts, security and billing** | Sign-in with a second step, roles and permissions, plans and payments. | The team's data stays safe and private. |
