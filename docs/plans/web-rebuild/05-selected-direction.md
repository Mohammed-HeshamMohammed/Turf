## Business story

Caller Whale is a desktop CRM for people working property leads: organize property/owner lists, review supplied phone evidence, prepare outreach, record outcomes, follow up and hand work between team members. Architecture supplies domain context; the software must remain the focus. Avoid resembling a brokerage, property marketplace, building developer or architecture practice.

Recheck claims against current feature documents, source and services. Phone-evidence ranking is not a promise to discover new owner numbers. Calling previews are not proof that live telephony has launched. Do not imply every operation works offline.

## Visual system

| Element | Selected treatment | Constraint |
| --- | --- | --- |
| Color | Warm ivory, charcoal, restrained peach | No lime palette; natural photographic colors allowed |
| Display type | Bold condensed grotesk, deliberate line breaks | Short headings only; never stretch a normal font |
| Body and controls | Readable geometric sans | Evaluate existing Schibsted Grotesk; verify any new font's license and loading |
| Small labels | Quiet spaced editorial labels; occasional monospace | Legible hierarchy, not tiny decorative paragraphs |
| Layout | Precise open grids, fine rules, aligned baselines | Avoid a repeated rounded-card wall |
| Controls | Mostly square/low radius, clear feedback | Normal readable form typography, adequate targets |
| Imagery | Residential architecture, facades, rooflines, strong perspective | Not listings sold through Caller Whale; record rights/provenance |
| Layering | Hero image passes behind selected headline edges | Live HTML text; preserve contrast and reading order |
| Product proof | Actual current app captures | Adjacent sample/preview captions; no generated replacement UI |
| Dashboard | Same tokens with compact rows and disciplined navigation | Decorative buildings do not occupy task tables |

Starting concept values: ivory #F4EFE7, charcoal #202321, peach #FFB594. These are proposals to test, not a contrast certification. Use charcoal text on peach. Define accessible error/success/focus tokens separately with text/icons. Dark mode uses distinct charcoal surface levels, warm light text and the same peach accent, never blanket image inversion.

Preserve the actual production brand mark until a separate logo change is approved. The generated wordmark does not authorize replacing it.

## Layout, layering and motion

Use a shared 4px scale and 8px multiples for primary rhythm. Explore a 1200–1320px content width, fluid gutters, 12-column desktop composition and a single-column phone layout. Draft hero split is roughly 55% copy/45% image with overlap at the meeting edge. The concept board's two-page proportions are not a production layout requirement.

Keep headline text in HTML over a separate responsive image. Choose focal points and clear negative space; use a deliberate scrim only as necessary. At narrow sizes put copy/actions before the photograph and reduce overlap before reducing legibility. Check fallback fonts, long text and zoom. Reserve image dimensions; never bake essential copy into a picture.

Motion should clarify state, not delay reading. Explore 150–250ms controls and section entrances up to 400ms. No scroll hijacking, moving imagery behind active reading text, automatic slides or content permanently hidden without JavaScript. Reduced-motion displays the final composition immediately.

## Account-entry and other pages

Sign-in/signup use a narrow residential-photo panel with concise return-to-work copy beside a spacious ivory form. Form first on mobile; remove or shorten decoration. The email-first reference is a sequencing concept, not implemented passwordless access or approval to open public registration.

Features adopts editorial product stories and real screens; Pricing adopts precise controls and tables while keeping tested arithmetic; Compare uses factual rows; Security/Contact use quieter layouts; Privacy/Terms prioritize reading and avoid image-heavy heroes. Dashboard uses compact structure with the same brand, not oversized marketing headings everywhere.
